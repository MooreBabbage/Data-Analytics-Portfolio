## Fidelity and reproducibility

This is a **transcription**, not a corrected or refactored version of the coursework. It preserves the original SQL as displayed, including omitted semicolons and other potential execution issues. It is **not** a standalone executable demo: the original MySQL databases and their schemas (`moores_guitar_shop`, `ap`, and `courses`) are not included. Some statements change database contents; do not run the scripts against valuable data without a backup.
